**Are reviews tied to real users?**
- As a user, I want reviews to be tied to real users so that I can trust the feedback 
is from actual buyers and not paid or fake reviews.

**I bought something but it is not in my account.**
- As a user, I want the products I purchase to be attached to my account
so that I can view my purchase history and access a receipt later.

**Products must be tied to vendors.** 
- As an admin, I want each product to be tied to a vendor so that the database can track who is selling 
each product and customers can see what each vendor has available.

**Transactions must link users and products.**
- As an admin, I want every transaction to link a user and a product so that 
the database can accurately track purchases.

**“I changed the price but nothing updated.”**
- As a vendor, I want to update my product prices so that my listings reflect 
current market conditions.

**I want to read reviews before buying.**
- As a user, I want to be able to read product reviews so that I can determine whether the
product meets my expectations before making a purchase.
